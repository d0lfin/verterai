# VerterAI

Это пример проекта, демонстрирующий автоматическую генерацию UI-тестов для Android-приложения при помощи моделей Anthropic.

## Содержимое репозитория

- `example/` – простое Android‑приложение на Kotlin (список задач) и место для сгенерированных тестов.
- `coder/` – агенты для создания интерфейсов DSL и реализаций UIAutomator2.
- `explorer/` – модуль исследования сценариев взаимодействия с устройством.
- `main.py` – пример запуска всего цикла генерации и сборки.
- `server.py` – минимальный сервер MCP для управления устройством через uiautomator2.

## Требования

- Python 3.10+
- Установленные зависимости из `requirements.txt`
- Файл `.anthropic_token` со строкой API‑ключа Claude
- Доступ к Android‑эмулятору или устройству с включённым `adb`

## Быстрый старт

```bash
# установка зависимостей
pip install -r requirements.txt

# запуск генерации тестов
python main.py
```

Функция `launch_agent` в `main.py` может либо записать новый трейс взаимодействий (`record_trace=True`), либо использовать сохранённый файл `data.json`.
Сгенерированные тесты будут помещены в каталог `example/app/src/androidTest/java/verterai/example/`.
Затем `GradleBuildAgent` попытается собрать проект и при необходимости исправить ошибки компиляции.

## Структура тестов

Агенты создают DSL‑интерфейсы и их реализации для UIAutomator2. Шаблоны подсказок лежат в `coder/prompts/`. Алгоритм состоит из нескольких этапов:

1. **ScenarioExplorer** разбирает текстовый сценарий действий пользователя и получает информацию об элементах экрана.
2. **Automator** на основе трассы генерирует Kotlin‑файлы с интерфейсами и реализациями.
3. **GradleBuildAgent** запускает сборку Gradle и через LLM устраняет возникшие ошибки.

## Пример Android‑приложения

В каталоге `example/` находится минимальное приложение со списком задач (`MainActivity.kt`). Оно служит целью для сгенерированных UI‑тестов.
